# 仕様書：マタタビ誘導型カオス猫パズル

## 【ゲームタイトル】
**マタタビ大合唱 ～モフモフ・カオス・タワー～**

---

## 【概要】
HTML5 Canvas、素のJavaScript、Web Audio APIのみで構築された、1日実装可能なシュール系ブラウザパズルゲーム。
複雑な物理演算やマッチ3パズルのような消去ルールは一切なし！プレイヤーは画面上に「マタタビ」を配置し、次々と降ってくる気ままな猫たちを誘導して画面いっぱいに積み上げていきます。
画面が猫だらけになると、猫たちが一斉に大合唱（ニャーニャー大合唱）を始めてカオスなフィナーレを迎える、笑える癒やし系（？）ゲームです。

---

## 【コア体験/ゲーム性】
1. **マタタビ誘導のシュールさ**
   - プレイヤーがクリック/タップした位置にマタタビが出現。猫たちは本能的にマタタビに向かってヨチヨチと歩いたり、転がったりして寄ってきます。
2. **シンプルで気持ちいい「積み上げ」**
   - 猫は上からランダムにポトポト降ってきます。重力と簡易的な当たり判定のみで、モフモフした塊が積み重なっていく様子を楽しみます。
3. **カオスな大合唱フィナーレ**
   - 一定数以上の猫が画面内にたまると、Web Audio APIで生成した多様な「ニャー」という鳴き声がハーモニー（？）を奏で、画面がカオスに包まれてクリア（またはスコア確定）となります。

---

## 【操作方法】
- **マウス左クリック / 画面タップ**: 
  - フィールド上の任意の場所に「マタタビ」を配置する。
  - マタタビは一定時間（または猫が到達するまで）その場に残り、消滅すると再度配置可能になる。
- **Rキー / リトライボタン**:
  - ゲームオーバー時やリセットしたい時に即座に最初からやり直せる。

---

## 【開発手順（エンジニアAIへの指示用）】

以下の構成・要件に従い、外部ライブラリ（PhaserやThree.js等）を一切使用せず、**単一のHTMLファイル（HTML + CSS + JavaScript）**で動作する完全なコードを出力してください。

### 1. ファイル構成
- `index.html` のみ（CSSとJSはHTML内にインラインで記述）。

### 2. 画面レイアウト（UI/UX）
- **解像度**: スマホ・PC両対応のレスポンシブ（Canvasサイズは 400×600px を基準とし、CSSで画面中央に配置）。
- **背景**: 部屋の壁と床をイメージしたシンプルで温かみのある色合い。
- **UI表示**: 
  - 上部に「積んだ猫の数（スコア）」と「制限時間/ゲージ」を表示。
  - ゲームオーバー判定：猫が画面最上部（天井ライン）を超えた状態で一定時間経過するとゲームオーバー。

### 3. 実装コンポーネント（JS）
- **ゲームループ (`requestAnimationFrame`)**:
  - 状態管理（タイトル画面、プレイ画面、ゲームオーバー/大合唱画面）。
- **オブジェクト管理**:
  - **猫クラス (Cat)**: 
    - 座標 `(x, y)`、速度 `(vx, vy)`、サイズ、向き、スプライト（Canvasの図形描画で可愛い猫の顔や耳を表現）。
    - 簡易物理：重力加速度、床および画面壁面との当たり判定、猫同士の押し出し合い。
    - 思考ルーチン：一番近いマタタビの方向へちょこちょこ移動する。
  - **マタタビクラス (Matatabi)**:
    - プレイヤーが置いた位置に存在し、猫を引き寄せる座標データ。
- **Web Audio API によるサウンド生成**:
    - 外部の音声ファイルを読み込まず、`AudioContext` を使用して「ニャー」という高低差のある電子音（オシレーターとゲインノードを使用）を動的に生成し、猫が重なった時やゲームクリア時に再生する。

### 4. 処理のフロー
1. ページ読み込み完了後、タイトル画面を表示。「START」クリックでゲーム開始。
2. 一定時間ごとに画面上部からランダムなX座標で猫が落下。
3. プレイヤーがクリックした位置にマタタビを設置、猫がそれに引き寄せられる。
4. 猫が積み重なり、規定数（例: 30匹）に達するか、時間切れになると「大合唱モード」へ移行。
5. Web Audio APIで一斉に鳴き声を奏で、「CAOS CLEAR!」の文字を表示してリザルトへ。
