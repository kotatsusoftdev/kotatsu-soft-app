## 概要

HTML5 Canvas・素の JavaScript・Web Audio API のみで動く、ブラウザ向けシュール系積み上げパズル。

テーマ名は「テトリスと猫」だが、テトロミノ操作・ライン消去・グリッド盤面は採用していない。テトリス由来は「上から落ちて積み上がる」メタファーのみで、実体はマタタビで猫を誘導してタワーを高く積むゲームである。

複雑な物理演算やマッチ3的な消去ルールはなく、重力と簡易当たり判定でモフモフした塊が積み重なっていく様子と、後半の巨大猫フィーバー／ニャー合唱がコアである。

---

## コア体験 / ゲーム性

1. **マタタビ誘導のシュールさ**  
   クリック／タップ位置にマタタビを置き、**着地後**の猫だけがヨチヨチと寄ってくる。落下中の猫は重力のみで落ちる。
2. **高さスコアの積み上げ**  
   猫は上からポトポト降る。スコアは匹数ではなく、床から最上端までの**つみあげ高さ（段）**。
3. **大合唱フィーバー**  
   残り10秒で巨大猫が降り始め、Web Audio の合唱音とともにカオスなボーナスタイムへ。時間切れで `CAOS CLEAR!` と最終段数を確定する。

---

## 操作方法

| 入力 | 動作 |
|------|------|
| マウス左クリック / 画面タップ（プレイ中） | フィールド上にマタタビを配置。**既存があっても毎回再配置可** |
| クリック / タップ（タイトル・リザルト） | ゲーム開始 |
| Space | タイトル／リザルトから開始 |
| Rキー | タイトルへ戻る（リトライ） |
| 「Xでシェア」ボタン（リザルト／ゲームオーバー） | スコア付き投稿文で X（Twitter）intent を開く |

マタタビは一定時間（約 5.5 秒）または猫が到達して消費されるまで残る。再配置の制限はない。

## ルール詳細（現行）

コード定数ベース。実装と食い違う場合は `001_matatabi_chaos/src/index.html` を優先する。

| 項目 | 内容 |
|------|------|
| 制限時間 | 合計 **30秒**（通常 約20秒 ＋ フィーバー **10秒**） |
| フィーバー開始 | 残り時間が `FEVER_DURATION`（10秒）以下になったとき |
| フィーバー内容 | **2倍サイズ**（`GIANT_SCALE = 2`）の猫が落下。出現間隔を短縮（1.4s → 0.9s）。合唱音を再生 |
| 猫の出現 | 画面上部のランダム X。通常間隔 `SPAWN_INTERVAL = 1.4` |
| マタタビ誘導 | **`onGround` の猫のみ**。歩行速度 `CAT_WALK_SPEED = 150`。寿命 `MATATABI_DURATION = 5.5` |
| スコア | **つみあげ高さ（段）**。床〜最上端の距離 ÷ `STACK_UNIT` |
| 段の定義 | `STACK_UNIT = CAT_HEIGHT * (1 - OVERLAP_RATIO)`、`CAT_HEIGHT = 30`、`OVERLAP_RATIO = 0.2`。通常猫＝1段、巨大猫＝ちょうど2段 |
| 高さ上限 | **無制限**（途中案だった12段クリア条件は撤廃） |
| クリア / リザルト | 時間切れで `CAOS CLEAR!`。スコアは最終つみあげ高さ（段）。「Xでシェア」でスコア付き投稿可 |
| ゲームオーバー | **制御不能な空中の猫**（`!onGround`）が天井ライン（`CEILING_Y`）を超えた状態が約 **2.2秒**（`CEILING_FAIL_TIME`）続く場合。安定して積まれたタワーの天井超えは失格にしない。リザルト同様「Xでシェア」可 |

### 主要定数（参考）

```
FLOOR_Y / CEILING_Y … 床・天井ライン
GRAVITY = 320 / MAX_FALL_SPEED = 230
CAT_HEIGHT = 30 / OVERLAP_RATIO = 0.2 / STACK_UNIT = 24
TIME_LIMIT = 30 / FEVER_DURATION = 10
SPAWN_INTERVAL = 1.4 / FEVER_SPAWN_INTERVAL = 0.9
MATATABI_DURATION = 5.5 / CEILING_FAIL_TIME = 2.2
CAT_WALK_SPEED = 150 / GIANT_SCALE = 2
```

## 実装構成（現状）

### ファイル構成

- 本体: `game-projects/001_matatabi_chaos/src/index.html`（CSS / JS インライン）
- 外部ゲームライブラリは不使用。プレイ数送信のみ `game-projects/common/stats.js` を読込（`sendPlayCount("matatabi_chaos")`）
- サムネ: `game-projects/assets/matatabi_thumb.png` 等
- ポータル: `game-projects/index.html` からリンク

### 画面レイアウト

- Canvas **400×600**（CSS でレスポンシブ中央配置）
- 背景: 部屋の壁と床をイメージした暖色
- HUD: つみあげ段数・残り時間。フィーバー中はオーバーレイ表示

### 状態遷移

`TITLE` → `PLAYING` → `RESULT`（時間切れクリア）または `GAMEOVER`

### オブジェクト

- **Cat**: 座標・速度・サイズ・向き。Canvas 図形描画（体・耳・目など）。重力、壁、着地（`landingSurfaceY`）、同高さ同士の押し合い。接地時のみマタタビへステア
- **Matatabi**: プレイヤー配置座標。緑グローとラベル。消費／寿命で消滅

### サウンド

外部音声ファイルなし。`AudioContext` でオシレーター生成（着地鳴き声、フィーバー合唱など）。

### プレイテストで固まった補足（要約）

- 着地・積み上げ判定、誘導速度、耳の見た目などは Round 1–2 で修正
- スコアを高さ段数化し、フィーバーを「巨大猫が降る」形に Round 3–4 で再定義
- 巨大猫の段数誤差（固定食い込み）を Round 5 で比例食い込み（`OVERLAP_RATIO`）に修正し、通常1段・巨大2段に統一
