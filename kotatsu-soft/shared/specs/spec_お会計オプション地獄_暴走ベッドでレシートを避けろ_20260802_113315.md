## 概要

HTML5 Canvas・素の JavaScript・Web Audio API のみで動く、ブラウザ向けシュール系回避アクション。

プレイヤーは点滴付きの**縦長ベッド**に乗った入院患者。病室廊下を爆走しながら、画面上部の**ナース**が投げつける理不尽な追加料金レシートを左右に避ける。当たれば請求が増え画面下に明細が積み上がるが、¥コインで収入を得て持ち直せる。

採点は **所持金 = 収入 − 請求**（多いほど良い）。60日（60秒）耐えれば退院クリア。所持金が ¥-100,000 以下で破産＝ゲームオーバー。

---

## コア体験 / ゲーム性

1. **落下レシートの左右回避**  
   上から降るレシートを左右移動とダッシュでかわす。理不尽な明細名がシュールさの核。
2. **当たるが耐える経済ループ**  
   被弾で請求増＋積み上げ圧迫。コイン取得で収入増。ピンチほどコインが増え、余裕ほどレシートが増える適応スポーン。
3. **退院までの60日カウント**  
   1秒＝1日。マイルストーンや終盤ラッシュでテンポを上げ、生還＝退院スタンプ演出。
4. **破産の走馬灯と生還の対比**  
   所持金下限到達で心拍停止＋当たった明細の走馬灯。生還時はハッピー退院演出。

## ゲームルール（現行）

### 時間・勝敗

| 項目 | 内容 |
|------|------|
| 制限時間 | **60秒**（表示は「退院まであと N日」） |
| クリア | 60日耐える → `CLEARING`（退院スタンプ等）→ リザルト |
| ゲームオーバー | 所持金 ≤ **¥-100,000**（`HELD_FLOOR`）→ `DYING`（心拍停止＋走馬灯）→ リザルト |
| スコア | **所持金 = 収入 − 請求**（多いほど良い） |
| ハイスコア | `KotatsuStorage`（`receipt_bed_dash` / `bestHeld`）。クリア／破産どちらでも更新可 |

### 経済

| 項目 | 内容 |
|------|------|
| 収入 `income` | ¥コイン取得額の累計 |
| 請求 `bill` | レシート被弾の累計（ダッシュすり抜けで最大 ¥700 減） |
| 所持金 | `income - bill`。HUD／結果／シェアの主役 |
| コイン heal | `17500`〜`29400` 相当（`COIN_HEAL_MIN` + range、平均 ≈ 23450） |
| コイン間隔 | ベース約1.55秒、下限0.38秒。債務が高いほど短縮・二重スポーンあり |

### プレイヤー（暴走ベッド）

| 項目 | 内容 |
|------|------|
| 見た目 | **縦長ベッド**（頭が上）＋患者＋点滴 |
| 被弾 | 請求加算、画面下に明細スタック、自機が上へ押し上げ（`MAX_STACK_LIFT = 4` 上限） |
| コイン取得 | 収入加算。スタックを1〜3枚解除して押し上げを緩和 |
| ダッシュ | 速度620・時間0.12秒・無敵0.16秒・冷却0.58秒 |

### レシート／ナース

| 項目 | 内容 |
|------|------|
| 発生 | 画面上部のナースが投擲してから落下 |
| 形状 | 通常／縦長／小型高速など |
| 動き | fall / sway / zigzag / surge ＋個体 `speedMul` |
| 幅 | プレイ幅に対し必ずベッド通過ギャップを残す（塞ぎ防止） |
| 危険ナース | 高単価・威圧口調。頻度はプレイテストで調整済み |
| 適応スポーン | 債務低→レシート多め／債務高→コイン多め |

### その他ギミック

- **お見舞いラッシュ**: まれにコイン連続落下  
- **マイルストーン**: 残り30/10/5/3日のテロップ  
- **会計準備ラッシュ**: 終盤の密集ウェーブ予告  
- **所持金ゲージ／赤字警告**: 所持金の可視化とマイナス転落演出  
- **結果称号**: 所持金帯の肩書き、収入／請求バー比較  
- **心拍 SFX**: ピンチでテンポ上昇（Web Audio）  

### 画面遷移

`TITLE` → `PLAYING` →（生還）`CLEARING` → `GAMEOVER`（リザルト）

## 当初計画（Go 時仕様）との差分

当初ドキュメント（本ファイル初版）は「お会計オプション地獄」名義の企画草案だった。以下は**当初 → 現行**の主な差。

| 項目 | 当初計画 | 現行実装 |
|------|----------|----------|
| タイトル | お会計オプション地獄：暴走ベッドでレシートを避けろ | **高額請求病院：暴走ベッドでレシートを避けろ！** |
| 移動軸 | ベッド上下、レシートは右→左（または奥→手前） | **ベッド左右、レシートは上→下** |
| 操作 | ↑↓ / W S、Space＝ジャンプ系 | **←→ / A D、Space＝ダッシュ**。スマホは左右ドラッグ＋ダブルタップ |
| ライフ | HP（体力）あり | **HPなし**。所持金下限で破産 |
| スコア | 総請求額（高いほど？／リザルト表示） | **所持金＝収入−請求**（多いほど良い）。キー `bestHeld` |
| 制限時間 | 1〜2分程度のスコアアタック（秒数明記なし） | **厳密60秒＝60日**。生還クリア／破産GO |
| 回復 | なし | **¥コイン**で収入加算（平均約 ¥23,450） |
| 被弾演出 | 赤字文字乱舞＋フラッシュ | 乱舞に加え**下積み上げ＋自機押し上げ**、明細走馬灯（死亡時） |
| ギリ回避 | スローモーション回避ボーナス | **廃止**（ダッシュすり抜けの「華麗な回避」割引のみ） |
| プレイヤー見た目 | 点滴ベッド（横長想定） | **縦長ベッド**＋患者描画 |
| スポーン演出 | レシートが流れてくる | **ナースが上部から投擲** |
| 背景 | 廊下疾走のニュアンス | **病室廊下**（部屋番号・蛍光灯・市松床など） |

- 理不尽な追加料金レシートをかわすシュールさ  
- 点滴付き暴走ベッドのプレイヤー像  
- Canvas 図形描画＋単一 HTML、外部エンジンなし  
- 赤字乱舞など被弾のコミカル演出  
- 経過とともに疾走速度が上がるテンポ感
