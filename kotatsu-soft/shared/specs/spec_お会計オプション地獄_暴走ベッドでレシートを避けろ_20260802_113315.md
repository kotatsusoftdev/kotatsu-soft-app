# お会計オプション地獄：暴走ベッドでレシートを避けろ

## 【ゲームタイトル】
お会計オプション地獄：暴走ベッドでレシートを避けろ

## 【概要】
点滴がついたまま病院の廊下を暴走するベッドにまたがり、次々と飛んでくる「理不尽な追加料金レシート（例：特選・枕の空気代、謎の面会謝絶料）」を華麗に避ける、1画面完結型の単一HTMLランアクションゲームです。
Canvasの軽快な図形描画を活かしたスムーズな動作に、画面を覆い尽くす赤字の追加オプション文字やスローモーション回避演出を組み合わせ、SNSで思わずシェアしたくなる圧倒的なシュールさと中毒性を生み出します。

## 【コア体験/ゲーム性】
- **直感的な高速回避アクション**: 上下移動のみのシンプルな操作で、次々と迫る巨大なレシートの隙間をすり抜けるスリル。
- **シュールな「追加料金」演出**: レシートに書かれた理不尽な項目名と、被弾時の「赤字文字乱舞」により、理不尽だけど笑えるデス演出を実現。
- **スローモーション回避**: ギリギリでレシートを回避した際にわずかなスローモーション（またはエフェクト）が発生し、スタイリッシュな逃走劇を演出。
- **短期集中型スコアアタック**: 1プレイ1〜2分程度で遊べ、最終的な「総請求額（スコア）」がSNS拡散用のリザルトとして表示されます。

## 【操作方法】
- **PC操作**:
  - `↑` キー / `W` キー：ベッドを上に移動
  - `↓` キー / `S` キー：ベッドを下に移動
  - `Space` キー：ジャンプ（または特殊回避）
- **スマホ操作**:
  - 画面の上下タップ、またはドラッグ操作でベッドを移動

## 【開発手順（エンジニアAIへの指示用）】

以下の仕様に従い、単一の `index.html` ファイル（HTML + CSS + JavaScriptを一体化）として実装を行ってください。外部の画像・音声ファイルは使用せず、すべてCanvasの図形描画とWeb Audio API（または視覚エフェクト）で完結させること。

### 1. 画面構成とレイアウト
- **解像度**: スマートフォンでのプレイを想定し、縦長（例: 400x700px）またはレスポンシブで画面中央に配置。
- **UI配置**:
  - 画面上部：現在の「総請求額（スコア）」、残り体力（HP）、スピードメーター。
  - 画面中央：点滴ベッドのプレイヤーキャラ、迫り来るレシート障害物。
  - 画面下部（リザルト時）：最終請求額と「SNSでシェアする」風のテキスト表示。

### 2. キャラクター・オブジェクト仕様（Canvas描画）
- **プレイヤー（暴走ベッド）**:
  - 四角形やパスを組み合わせ、点滴スタンドと車輪がついたベッドを簡易的かつコミカルに描画。
  - 上下移動時にわずかに傾くなど、疾走感のある座標変換・アニメーションを実装。
- **障害物（レシート）**:
  - 白い長方形をベースに、ギザギザの切り取り線（下部）を描画。
  - レシート表面には「特選・空気代」「謎の管理費」などのランダムテキスト（または疑似的な文字の線）を配置。
  - 画面右側から左側へ向かって（または奥から手前へ）ランダムな高さで流れてくる。

### 3. ゲームシステム・演出
- **メインループ**:
  - requestAnimationFrameを用いた滑らかな60fps描画。
  - 経過時間とともにスクロール速度（ベッドの疾走速度）が上昇する難易度上昇システム。
- **ヒット判定と被弾演出**:
  - プレイヤーとレシートのAABB（矩形）当たり判定。
  - 被弾時には画面全体に赤字の「追加！」「赤字！」の文字が乱舞し、画面が赤くフラッシュする演出。
- **回避ボーナス（スローモーション）**:
  - レシートのギリギリをかすめて避けた際、一時的にゲームスピードがスローになり、スタイリッシュな回避音（ビープ音）とエフェクトが発生。

### 4. 実装要件（単一ファイル制約）
- 外部ライブラリの使用は最小限にする（必要に応じて軽量なフォントやCanvas描画補助のみ）。
- コードはモジュール化し、コメントを充実させること。
- エラーハンドリングを行い、ゲームオーバーからリトライまでスムーズに移行できるようにする。
