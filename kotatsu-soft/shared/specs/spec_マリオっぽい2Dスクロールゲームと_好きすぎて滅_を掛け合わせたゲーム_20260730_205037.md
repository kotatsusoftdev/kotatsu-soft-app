# 愛が重すぎて敵もうっとり消滅しちゃう！爽快シュールアクションゲームの決定版

## 【ゲームタイトル】
**「重愛パニック！ ～うっとり消滅デイズ～」**

## 【概要】
プレイヤーは「愛が重すぎる主人公（キューピッド見習い）」を操作し、街にあふれる魔物やライバルたちに対して「重すぎる愛の波動（ハート、ポエム、手作り弁当の幻影など）」を浴びせかけるシュールなアクションゲームです。
攻撃された敵は、最初は困惑し、次にその「重すぎる愛」のプレッシャーにうっとり（あるいはドン引き）しながら、最終的にハートマークを浮かべて愛の重さに耐えきれず消滅（昇天）していきます。
ド派手なエフェクトとコミカルなリアクションが癖になる、爽快感とシュールレアリズムが融合した作品です。

## 【コア体験/ゲーム性】
- **「圧倒的な物量と重さ」による爽快感**: 軽快なアクションで敵をなぎ倒すのではなく、「愛の重さ」で敵を物理的・精神的に押しつぶして消滅させる独特の快感。
- **シュールなユーモア**: 敵が「重っ…！でも嫌いじゃないかも…？」などのセリフや情けないモーションを浮かべて消えていくシュールな世界観。
- **コンボとゲージ管理**: 愛を叫びすぎるとプレイヤー自身が酸欠になる（愛の暴走）ため、クールダウンを挟みつつ効率よく敵を処理する戦略性。

## 【操作方法】
- **移動**: `WASD` キー または `左スティック`
- **通常攻撃（重い愛の弾丸）**: `J` キー または `Aボタン` （前方にハートの弾を連射）
- **スペシャル攻撃（愛のヘビープレス）**: `K` キー または `Bボタン` （画面全体の敵をうっとりさせつつ大ダメージ。要ゲージ）
- **回避/愛の逃避行**: `Space` キー または `Xボタン` （素早くダッシュして敵の攻撃を避ける）

## 【開発手順（エンジニアAIへの指示用）】

### 1. プロジェクトの初期設定
- 画面解像度 16:9（例: 1280x720）の2D/2.5Dアクションゲームとしてセットアップする。
- プレイヤーキャラクター、敵キャラクター、背景のプレースホルダー（仮スプライト）を作成する。

### 2. プレイヤー機能の実装
- `PlayerController.cs` を作成し、`WASD` による移動、ダッシュ、通常攻撃の入力処理を実装する。
- 「愛の暴走ゲージ」のロジックを追加し、攻撃し続けるとゲージが溜まり、マックスになると一定時間行動不能になるペナルティを実装する。

### 3. 敵（エネミー）機能の実装
- `Enemy.cs` を作成し、プレイヤーに向かって移動するAIを実装する。
- 敵のステータスとして「HP（愛耐性）」を持たせ、プレイヤーの攻撃を受けるとHPが減少し、同時に「うっとり度」の表情変化（アニメーション遷移）を起こすようにする。
- HPが0になった際、ハートマークを周囲に散らしながら消滅する演出（パーティクルシステム）を実装する。

### 4. UI・演出・ゲームループの実装
- プレイヤーのHP、愛の暴走ゲージ、スコア（消滅させた敵の数）を表示するUIを作成する。
- スペル攻撃発動時の全画面エフェクトと、コミカルなテキストポップアップ（「重い！」「最高にヘビー！」など）を実装する。
- タイトル画面、ゲームプレイ画面、スコアアタック終了時のリザルト画面の遷移を構築する。
