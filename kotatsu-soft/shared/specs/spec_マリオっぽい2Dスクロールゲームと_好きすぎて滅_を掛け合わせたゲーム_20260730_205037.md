## 概要

HTML5 Canvas・素の JavaScript・Web Audio API のみで動く、ブラウザ向けシュール系スコアアタックアクション。

プレイヤーは**アイドル**。押し寄せる**ファン**の推し愛をハート弾と必殺で受け止め、うっとり「滅」させる。叫びすぎると自身がファンの愛に押し潰される（暴走）が、その状態でも**アンコール必殺**で最高潮を返せる。

テーマ名に「マリオっぽい2Dスクロール」とあるが、ジャンプ／足場プラットフォーマーは採用していない。横長アリーナ＋カメラ追従でスクロール感を出し、操作はマウスカーソル追従の自由移動＋射撃である。

---

## コア体験 / ゲーム性

1. **愛の物量でファンをうっとり消滅**  
   なぎ倒しではなく、ハート弾・軌跡・エコー・必殺で「好き」を浴びせて「滅」させる。
2. **愛圧と時間の盛り上がり**  
   30秒のライブ。時間とともに愛圧が上がり、スポーン増・攻撃が派手に進化。終盤は「究極の愛」。
3. **暴走とアンコールの緊張**  
   攻撃しすぎると低速・ファン加速のピンチ。必殺だけは撃てる（アンコール）ので逆転の余地がある。
4. **好きすぎて滅の儀式感**  
   撃破の巨大「滅」、コンボ、クリア時の滅連鎖フィナーレ。

## 操作方法（現行）

| 入力 | 動作 |
|------|------|
| マウス移動 | カーソル方向へ自動移動（到達付近で減速／停止）。向き・射撃方向もカーソル |
| 左クリック（押しっぱなし可） | 通常攻撃（ハート弾） |
| 右クリック | 必殺（SP 満タン時）。暴走中は **アンコール**（強化） |
| 中クリック / Shift | 回避ダッシュ（短時間移動＋無敵） |
| スマホ：画面タップ | タップ位置を目標点として移動 |
| スマホ：右下ボタン | 攻撃／SP／回避 |
| Enter / Space / タップ | タイトル・リザルトから開始／リトライ |
| Esc | リザルトからタイトルへ |

右クリックメニューは抑止済み。キーボード WASD／J／K／Space は主操作ではない（互換の一部キーは残る場合あり）。

## ゲームルール（現行）

### 時間・勝敗

| 項目 | 内容 |
|------|------|
| 制限時間 | **30秒** |
| クリア | 時間切れまで HP が残っていること → `CLEARING` 演出（約2.4秒）→ リザルト |
| クリアボーナス | 生還 +50。残ファンを一斉滅してスコア加算 |
| ゲームオーバー | HP 0。「ファンの愛に負けた…」 |
| ハイスコア | `KotatsuStorage`（`heavy_love_snake` / `highScore`） |

### 愛圧（時間連動）

`lovePressure = 1 - timeLeft / 30`（0→1）

| フェーズ | 目安 | 攻撃 | ファン |
|----------|------|------|--------|
| 1 | 序盤 | ハート1発 | 通常スポーン |
| 2 | 愛圧 ≥ 0.33 | 2連ハート | 間隔短縮・同時数増 |
| 3 | 愛圧 ≥ 0.66 | 扇状3発・弾が光る | さらに密・速度微増 |
| 4 究極の愛 | 残り ≤ 5秒 | 3発＋ダメ最大 | スポーン加速、撃破スコア×2 |

### プレイヤー

| 項目 | 内容 |
|------|------|
| HP | 100。ファン接触で減少 |
| 愛の暴走ゲージ | 攻撃で増加。満タンで約1.8秒ロック |
| 暴走中 | 低速移動（約0.28倍）のみ。通常攻撃・回避不可。**必殺（アンコール）は可**。周囲ファンに圧殺 DOT。ファン速度約1.55倍 |
| SP | ヒット／撃破／サイリウム／圧殺で増加。満タンで必殺 |
| アンコール | 暴走中必殺。ダメージ約1.25倍。「推しが応えた！！」 |

### ファン（内部名 enemies）

| 項目 | 内容 |
|------|------|
| AI | アイドルへ接近 |
| 愛耐性 HP | 攻撃で減少。段階 通常→困惑→うっとり（表情・サイリウム色） |
| 撃破 | 巨大「滅」＋ハート散らし＋ポップ＋サイリウムドロップ＋告白エコー |
| 視線の愛 | カーソル付近だと引き寄せ／微スタン |

### スコア・コンボ

| 項目 | 内容 |
|------|------|
| 基本 | 撃破ごとにコンボ倍率分加算（上限×8） |
| 滅コンボ | 1.2秒以内の連続撃破で継続。5以上で滅フィーバー（連射強化） |
| サイリウム拾得 | SP 回復＋スコア +1 |

### その他ギミック

- **愛の軌跡**: 移動でハート残滓。接触で小ダメ＋硬直  
- **告白エコー**: 撃破位置の残響円（継続ダメ）  
- **好きビーム**: 自機→カーソルの視線ライン（愛圧で強調）  
- **心拍 SFX**: プレイ中の弱いパルス（愛圧でテンポ上昇）  

### 画面遷移

`TITLE` → `PLAYING` →（クリア）`CLEARING` → `RESULT`  
          ↘（撃破）`RESULT`

統計: プレイ開始時 `KotatsuStats.sendPlayCount("heavy_love_snake")`。
