## 最終仕様スナップショット（このチャット後）

プレイテスト反映後の現行ルール（コード定数ベース）。

| 項目 | 内容 |
|------|------|
| 操作 | クリック／タップでマタタビ配置（毎回再配置可）。Rキーでリトライ |
| マタタビ誘導 | **着地後（`onGround`）の猫のみ**誘導。落下中は重力のみ |
| 時間 | 合計 **30秒**（通常 約20秒 ＋ フィーバー **10秒**） |
| フィーバー | 残り10秒で開始。**2倍サイズ（`GIANT_SCALE = 2`）の猫**が落下。出現間隔短縮 |
| スコア | **つみあげ高さ（段）**。床から最上端までの距離 ÷ `STACK_UNIT` |
| 段の定義 | `STACK_UNIT = CAT_HEIGHT * (1 - OVERLAP_RATIO)`、`OVERLAP_RATIO = 0.2`。通常猫＝1段、巨大猫＝ちょうど2段 |
| 高さ上限 | **無制限**（12段クリア条件は撤廃）。時間切れでリザルト |
| ゲームオーバー | **制御不能な空中の猫**が天井ラインを超えた状態が約2.2秒続く場合。安定して積まれたタワーは対象外 |
| クリア／リザルト | 時間切れで `CAOS CLEAR!`。スコアは最終つみあげ高さ（段） |

## レビュー履歴（時系列）

### Round 1（初回テストプレイ）

#### 指摘

1. 猫が積み上がらず、うろうろしているだけになっている  
2. マタタビの誘導効果が弱く操作感がない  
3. 猫が出ただけでスコアがあがっている（積まれた数になっていない）  
4. 両耳の幅が狭く猫に見えない  
5. 大合唱の効果が何かわからない（フィーバータイム？）  
6. 90秒は長い。60秒で十分  

#### 原因

1. 着地が常に固定の `FLOOR_Y` にスナップされ、他の猫の上に乗れない構造だった  
2. 加速度＋強い摩擦で実効速度が極端に低かった  
3. `score = cats.length` で落下中も含めて数えていた  
4. 耳の三角形座標が中央寄りで左右が重なっていた  
5. 大合唱が演出のみでスコア／説明がなかった  
6. `TIME_LIMIT = 90`  

#### 対応

1. `landingSurfaceY()` を追加し、接地済み猫の上に乗る着地判定を実装。押し合いは同高さ同士の水平のみに変更  
2. 目標速度へのステアリング方式に変更（接地時の歩行速度を明示）  
3. `onGround` の猫のみスコアカウント  
4. 耳を頭部左右端に配置し直し  
5. 大合唱中のボーナス加点とリザルト内訳表示を追加（後続ラウンドで再設計）  
6. `TIME_LIMIT` を 60 に変更。スポーン間隔も短縮  

#### 変更ファイル

- `game-projects/001_matatabi_chaos/src/index.html`

### Round 2

#### 指摘

1. 猫が「乗る」判定後、画面上に飛んでいってゲームオーバーになる  
2. 「天井を超えたらゲームオーバー」は、積むほどポイントが増える設計と矛盾していないか  
3. 落ちてくる猫のスピードが速くてうまく詰めない  
4. マタタビはクリックのたびに位置を変更できるようにしたい  

#### 原因

1. `landingSurfaceY` が X 重なりのある高い支持面を無条件採用し、床の猫が山の上へ瞬間移動していた  
2. 天井判定が接地済み（安定積み）と空中の制御不能を区別していなかった  
3. 重力・初速が大きく、落下が速すぎた  
4. `placeMatatabi` に「既存マタタビ有効中は再配置不可」のガードがあった  

#### 対応

1. 支持面候補が「現在位置より大きく上」なら除外するよう修正  
2. `anyCatOutOfControlAboveCeiling()` に変更（`!onGround && y < CEILING_Y` のみ失敗）  
3. 重力低下・最大落下速度キャップ・初速低減  
4. 再配置ガードを撤廃し、クリックごとにマタタビを置き直せるように変更  

#### 変更ファイル

- `game-projects/001_matatabi_chaos/src/index.html`

### Round 3

#### 指摘

1. スコアが積み上がった猫の数になっていない。積み上がった合計の高さを算出したらどうか  
2. 合唱フィーバーのゲーム的な意味が分からない。でかい猫でスコアが倍になるなど、スコアと関連づけてほしい  

#### 原因

1. スコアが「着地匹数」のままで、見た目のタワー高さと一致しにくかった  
2. フィーバーが加点演出のみで、プレイ意図と結びつきにくかった  

#### 対応（当時）

1. `currentPileLevels()` で床〜最上部の高さを段数化。目標も「12段」に変更  
2. 大合唱で頂点猫が巨大化し、スコア×2ボーナスとする仕様を追加（後続 Round 4 で再定義）  

#### 変更ファイル

- `game-projects/001_matatabi_chaos/src/index.html`

### Round 4

#### 指摘

1. 落ちてくる猫はマタタビに誘導されないでほしい  
2. 大合唱フィーバーは、2倍の大きさの猫が落ちてきて積み上がる高さが2倍になるイメージ  
3. 12段が上限だとすぐ達成できるので無制限にしてほしい（画面上限超過時の扱いは未決）  
4. 合計30秒（通常20秒＋最後10秒がフィーバー）にしてほしい  

#### 原因／設計ギャップ

1. 空中でもマタタビへステアしていた  
2. 「既存猫の見た目拡大＋スコア倍率」は、ユーザー意図の「でかい猫が降る」とズレていた  
3. `CLEAR_HEIGHT` 到達でフィーバー／終了に入っていた  
4. `TIME_LIMIT = 60` でフィーバーが別ステートだった  

#### 対応

1. `onGround` のときだけマタタビ誘導  
2. フィーバー中は `spawnCat(true)` で **実体サイズ2倍**の猫を生成。高さスコアは物理高さから算出  
3. 高さクリア条件を撤廃。時間切れのみでリザルト。安定積みの天井超えは失格にしない（カメラ追従は未対応）  
4. `TIME_LIMIT = 30`、`FEVER_DURATION = 10`。残り10秒でフィーバー開始音・巨大猫スポーン  

#### 変更ファイル

- `game-projects/001_matatabi_chaos/src/index.html`

### Round 5（スコア計算の不整合）

#### 指摘

- 巨大猫が2倍の大きさならスコアは16段になるはずだが、リザルトが18段になっている  
- スコアの計算方法を確認してほしい  

#### 原因

着地時の「食い込み」がサイズに関わらず **固定 6px** だった。

- 通常猫（高さ30）: 消費高さ `30 - 6 = 24px` = `STACK_UNIT` → **1段**（正しい）  
- 巨大猫（高さ60）: 消費高さ `60 - 6 = 54px` → `54 / 24 = 2.25段`（本来2.0段であるべき）  

巨大猫が積まれるたびに 0.25 段分の誤差が蓄積し、見た目より高い段数になっていた。

#### 対応

- `OVERLAP_RATIO = 0.2` を導入し、食い込みを **猫の高さに比例**させる  
- `STACK_UNIT = CAT_HEIGHT * (1 - OVERLAP_RATIO)`  
- `landingSurfaceY` / 着地 `restY` も `cat.h * (1 - OVERLAP_RATIO)` に統一  
- 結果: 通常猫＝1段、巨大猫＝ちょうど2段  

#### 変更ファイル

- `game-projects/001_matatabi_chaos/src/index.html`
