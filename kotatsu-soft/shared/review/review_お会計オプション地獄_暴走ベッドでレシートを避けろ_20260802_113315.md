| 項目 | 内容 |
|------|------|
| 世界観 | 病室廊下を爆走する点滴ベッド。ナースが理不尽レシート／¥コインを投げる |
| 操作（PC） | `←→` / `A D` 左右移動。`Space` ダッシュ |
| 操作（スマホ） | ドラッグで左右、ダブルタップでダッシュ |
| 時間 | **60秒＝退院まであと60日**（1秒＝1日）。生還でクリア |
| スコア | **所持金 = 収入 − 請求**（多いほど良い）。保存キー `bestHeld`。クリア／破産どちらでも更新可 |
| ゲームオーバー | 所持金 ≤ **¥-100,000**（`HELD_FLOOR`）。`DYING`（心拍停止＋走馬灯）→リザルト |
| クリア | 60日耐えたら `CLEARING`（退院スタンプ演出）→リザルト |
| レシート | 上から落下。縦長／小型高速など形状差＋ sway/zigzag/surge。被弾で下に積み上げ＋自機が上へ（`MAX_STACK_LIFT` 上限あり） |
| コイン | 取得で収入加算。heal 平均約 **¥23,450**（旧比約70%）。ピンチ時は出現増 |
| ダッシュ | 短時間左右移動＋無敵。すり抜け時「華麗な回避」で請求 −¥700。冷却あり |
| 適応難易度 | 債務低→レシート多め／債務高→コイン多め。お見舞いラッシュ等 |
| セーブ／統計 | `KotatsuStorage`、`KotatsuStats.sendPlayCount("receipt_bed_dash")` |

### Round 2（落下回避・請求破産）

#### 指摘

1. レシートは上→下、ベッドは左右で避けたい  
2. 細かい文字は読めない。被弾時に明細を表示し、明細の多さを見た目で分かりやすく  
3. ライフ3ではなく請求額が一定でゲームオーバー  
4. 徐々に速度を上げるなどバランス変化をつけて  

#### 対応

1. 軸入れ替え（落下＋左右移動／Spaceダッシュ）  
2. ハッチ線＋件数バッジ。被弾時明細ポップアップ  
3. HP廃止 → 請求額 ¥100,000 で破産  
4. 速度・出現間隔・幅の難易度ランプ  

---

### Round 3（病院演出・コイン・死亡）

#### 指摘

1. スピード感が足りない  
2. お金アイテムで回復  
3. 病室っぽさ／入院中表現、ベッドに患者  
4. 赤字膨張で心拍停止→ドクロの死亡演出  

#### 対応

1. `SPEED` 引き上げ、スクロール／ブラー強化  
2. ¥コイン落下で請求減算  
3. 病室廊下描画＋患者付きベッド  
4. `STATE.DYING`（心拍→フラットライン→ドクロ）  

---

### Round 4（積み上げ圧迫）

#### 指摘

1. ×N バッジ不要  
2. コイン回復量アップ  
3. 幅が大きすぎて絶対に避けられないことがある  
4. レシートごとに速度・動きのバリエーション  
5. 被弾で下に積み上げ＋自機が上へ（切迫感＋明細表示）  

#### 対応

1. バッジ削除  
2. heal を約 ¥20,000〜¥35,000 帯へ  
3. `MAX_RECEIPT_W`／ペア時中央ギャップ保証  
4. `speedMul` + fall/sway/zigzag/surge  
5. `stackedReceipts`＋`playerY` 上昇。コインでスタック解除  

---

### Round 5（60秒制・演出文言）

### Round 16（コイン収入30%減＋プログラム見直し）

#### 指摘

1. コインによる平均収入額を約30%減  
2. ゲーム全体のプログラム見直し

3. 軽いバランス整合としてコイン出現間隔をわずかに短縮（下限 `0.42 → 0.38` 等）。レシート頻度・落下速度は触らない
